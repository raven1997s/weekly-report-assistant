# Proposal: 改进数据库管理页面的搜索和查看体验

## Metadata

- **ID**: `improve-database-search`
- **Status**: `proposed`
- **Created**: 2026-01-16
- **Owner**: TBD

## Problem Statement

当前数据库管理页面存在以下用户体验问题：

1. **JSON 数据查看困难**
   - JSON 字段（如 `records`、`plans`、`reflections`）需要点击展开按钮才能查看详细内容
   - 展开后占用大量表格空间，影响其他行的查看
   - 无法在弹窗中独立查看 JSON 内容，复制不便
   - 嵌套结构显示不清晰，缺少语法高亮

2. **搜索功能不够灵活**
   - 当前只支持全局搜索（所有文本字段）或单字段搜索
   - 无法按多个条件组合搜索（如同时搜索"项目=WMS"且"内容包含bug"）
   - 无法按日期范围筛选（如查看本周的数据）
   - 无法按布尔值筛选（如只看已删除的记录）
   - 无法排序（如按创建时间倒序）

## Impact

- **用户体验**: 开发者调试数据时需要反复展开/折叠 JSON，操作繁琐
- **数据查找**: 难以快速定位特定条件的数据（如某个项目、某个时间范围）
- **效率**: 缺少筛选和排序功能，需要手动翻页查找目标数据

## Proposed Solution

### 核心改进

1. **JSON 数据弹窗查看器**
   - 点击 JSON 字段时打开模态弹窗，在独立空间中展示完整 JSON
   - 支持语法高亮、折叠/展开嵌套结构
   - 提供"复制 JSON"按钮，方便开发者复制到编辑器
   - 支持搜索 JSON 内容（Ctrl+F）

2. **高级筛选面板**
   - 添加筛选按钮，点击后展开筛选面板
   - 支持按字段类型显示不同的筛选器：
     - **文本字段**: 模糊匹配输入框
     - **日期字段**: 日期范围选择器
     - **布尔字段**: 下拉选择（全部/是/否）
   - 支持添加多个筛选条件，条件之间为 AND 关系
   - 提供"重置筛选"按钮

3. **列排序功能**
   - 点击表头可以进行升序/降序排序
   - 支持多列排序（点击多列表头）
   - 排序状态在表头显示箭头图标

## Alternatives Considered

### 1. 使用第三方 JSON 查看器库

**优点**: 功能强大，开箱即用
**缺点**: 增加依赖包体积，可能与现有风格不统一
**结论**: 不采纳，使用自定义轻量级方案

### 2. 在表格内直接展开 JSON

**优点**: 无需切换上下文
**缺点**: 占用大量空间，影响表格布局
**结论**: 已实现，但体验不佳，需改进为弹窗模式

### 3. 使用表格组件库（如 Element Plus）

**优点**: 内置排序、筛选功能
**缺点**: 需要重构现有代码，增加大量依赖
**结论**: 不采纳，在现有基础上改进

## Risks and Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| 大 JSON 数据导致弹窗性能问题 | 中 | 添加虚拟滚动，限制显示深度 |
| 筛选条件过多导致界面复杂 | 中 | 默认隐藏筛选面板，按需展开 |
| 排序功能影响查询性能 | 低 | 后端添加索引，优化 SQL 查询 |

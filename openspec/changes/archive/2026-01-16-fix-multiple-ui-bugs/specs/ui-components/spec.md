# Capability: UI Components

## MODIFIED Requirements

### Requirement: 设置页面删除按钮图标

设置页面 MUST 显示正确的删除按钮图标（垃圾桶），按钮在悬停时 SHALL 变为红色。

#### Scenario: 查看设置页面的删除按钮

- **GIVEN** 用户在设置页面
- **AND** 存在至少一个项目和一种工作类型
- **WHEN** 用户查看项目管理和工作类型的删除按钮
- **THEN** 所有删除按钮 MUST 显示垃圾桶图标
- **AND** 鼠标悬停时图标 SHALL 变为红色
- **AND** 图标大小 MUST 与周围按钮一致（16x16）

### Requirement: 定时任务系统任务不可编辑状态

系统 MUST 为系统任务（计划转换任务）显示不可编辑状态，整个卡片区域 SHALL 显示 `not-allowed` 光标。

#### Scenario: 系统任务卡片显示不可编辑状态

- **GIVEN** 用户在设置页面
- **AND** 存在至少一个系统任务（计划转换任务）
- **WHEN** 用户将鼠标悬停在系统任务卡片的任意位置
- **THEN** 鼠标光标 MUST 显示为 `not-allowed`（禁止符号）
- **AND** 系统任务卡片的背景色 SHALL 保持不变（不应有悬停高亮效果）
- **AND** 点击系统任务卡片 SHALL NOT 触发编辑弹窗

#### Scenario: 非系统任务保持可编辑状态

- **GIVEN** 用户在设置页面
- **AND** 存在至少一个非系统任务（用户创建的任务）
- **WHEN** 用户将鼠标悬停在非系统任务卡片的信息区域
- **THEN** 鼠标光标 MUST 显示为 `pointer`（手指符号）
- **AND** 非系统任务卡片 SHALL 显示悬停背景色变化
- **AND** 点击非系统任务卡片 MUST 触发编辑弹窗

### Requirement: 确认弹窗可见性

确认弹窗 MUST 在触发操作的页面显示，系统 SHALL 确保用户可以看到并确认操作。

#### Scenario: 从工作记录页面移到下周计划

- **GIVEN** 用户在工作记录页面（HomeView）
- **AND** 存在至少一条工作记录
- **WHEN** 用户选择一条记录并点击"移到下周计划"按钮
- **THEN** MUST 在工作记录页面显示确认弹窗
- **AND** 弹窗标题 MUST 为"移到下周计划"
- **AND** 弹窗内容 MUST 显示"确定要将选中的 N 条记录移到下周计划吗？"
- **AND** 用户 MUST 能够点击"取消"或"确认"按钮

#### Scenario: 确认后操作成功并显示提示

- **GIVEN** 用户在工作记录页面
- **AND** 用户已触发"移到下周计划"操作
- **AND** 确认弹窗已显示
- **WHEN** 用户点击"确认"按钮
- **THEN** 选中的记录 MUST 从工作记录列表中移除
- **AND** 选中的记录 MUST 被添加到下周计划
- **AND** MUST 显示成功提示："已将 N 条记录移到下周计划"
- **AND** 弹窗 MUST 关闭

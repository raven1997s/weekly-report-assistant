# Capability: Data Recovery

## MODIFIED Requirements

### Requirement: 回收站数据显示完整性

回收站 MUST 显示所有已删除的工作记录和周报，MUST 正确显示数量徽章，系统 SHALL 确保数据完整性。

#### Scenario: 回收站显示所有已删除的工作记录

- **GIVEN** 用户已删除了多条工作记录
- **AND** 数据库中存在 5 条 deleted=1 的记录
- **WHEN** 用户打开回收站页面
- **THEN** "已删除的工作记录"部分 MUST 显示全部 5 条记录
- **AND** 数量徽章 MUST 显示"5"
- **AND** 每条记录 MUST 显示：内容、项目、类型、删除时间

#### Scenario: 回收站显示所有已删除的周报

- **GIVEN** 用户已删除了多份周报
- **AND** 数据库中存在 3 份 deleted=1 的周报
- **WHEN** 用户打开回收站页面
- **THEN** "已删除的周报"部分 MUST 显示全部 3 份周报
- **AND** 数量徽章 MUST 显示"3"
- **AND** 每份周报 MUST 显示：周标签、日期范围、删除时间

#### Scenario: 从回收站恢复工作记录

- **GIVEN** 用户在回收站页面
- **AND** 存在至少一条已删除的工作记录
- **WHEN** 用户点击某条记录的"恢复"按钮
- **AND** 用户确认恢复操作
- **THEN** 该记录 MUST 从回收站移除
- **AND** 该记录 MUST 在工作记录列表中重新出现
- **AND** MUST 显示成功提示："工作记录已恢复"
- **AND** 回收站的数量徽章 MUST 更新

#### Scenario: 从回收站恢复周报

- **GIVEN** 用户在回收站页面
- **AND** 存在至少一份已删除的周报
- **AND** 该周报属于本周
- **WHEN** 用户点击该周报的"恢复"按钮
- **AND** 用户确认恢复操作
- **THEN** 该周报 MUST 从回收站移除
- **AND** 该周报 MUST 在生成周报页面重新出现
- **AND** 周报的"下周计划"和"本周总结" MUST 恢复到编辑状态
- **AND** MUST 显示成功提示："周报已恢复，可以继续编辑"

#### Scenario: 永久删除工作记录

- **GIVEN** 用户在回收站页面
- **AND** 存在至少一条已删除的工作记录
- **WHEN** 用户点击该记录的"永久删除"按钮
- **AND** 用户确认永久删除操作
- **THEN** 该记录 MUST 从回收站移除
- **AND** 该记录 MUST 从数据库中永久删除
- **AND** MUST 显示成功提示："工作记录已永久删除"
- **AND** 该操作 SHALL NOT 可恢复

#### Scenario: 永久删除周报

- **GIVEN** 用户在回收站页面
- **AND** 存在至少一份已删除的周报
- **WHEN** 用户点击该周报的"永久删除"按钮
- **AND** 用户确认永久删除操作
- **THEN** 该周报 MUST 从回收站移除
- **AND** 该周报 MUST 从数据库中永久删除
- **AND** MUST 显示成功提示："周报已永久删除"
- **AND** 该操作 SHALL NOT 可恢复

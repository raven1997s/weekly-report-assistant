## ADDED Requirements

### Requirement: 工作状态配置

系统 SHALL 允许用户在设置页维护工作记录可选状态，支持新增、编辑、删除和排序。

#### Scenario: 首次加载默认状态

- **WHEN** 系统不存在 `recordStatuses` 设置
- **THEN** 系统创建默认状态“待开始、进行中、待验证、已完成、已阻塞、已暂停”

#### Scenario: 修改状态配置

- **WHEN** 用户新增、编辑、删除或排序工作状态并保存
- **THEN** 系统将最新状态数组保存到 `settings.recordStatuses`
- **AND** 后续录入和编辑使用最新配置

#### Scenario: 删除已被历史记录使用的状态

- **WHEN** 用户从配置中删除一个已被历史记录使用的状态
- **THEN** 系统不修改历史记录的状态值
- **AND** 历史状态仍可显示和筛选

### Requirement: 工作记录状态持久化

系统 SHALL 为每条工作记录保存一个状态值，并通过工作记录 API 完整读写该字段。

#### Scenario: 新增带状态的记录

- **WHEN** 用户提交一条已选择状态的工作记录
- **THEN** 系统将状态保存到 `records.status`
- **AND** API 响应包含该状态

#### Scenario: 未显式选择状态

- **WHEN** 用户新增工作记录但未显式选择状态
- **THEN** 系统优先使用“已完成”
- **AND** 如果配置中不存在“已完成”，系统使用配置列表第一项
- **AND** 如果配置为空，系统回退为“已完成”

#### Scenario: 编辑工作记录状态

- **WHEN** 用户修改已有工作记录的状态
- **THEN** 系统更新 `records.status` 和 `updatedAt`
- **AND** 不改变记录的项目、工作类型和内容

#### Scenario: 兼容历史无状态记录

- **WHEN** 系统读取 `status` 为空的历史工作记录
- **THEN** 前端将该记录状态显示为“已完成”
- **AND** 周报生成和筛选均按“已完成”处理

### Requirement: 计划转换状态

系统 SHALL 将下周计划转换生成的工作记录状态设置为“进行中”。

#### Scenario: 单条计划转换

- **WHEN** 用户将一条下周计划转换为工作记录
- **THEN** 新工作记录的状态为“进行中”

#### Scenario: 定时或批量计划转换

- **WHEN** 系统定时或批量将计划转换为工作记录
- **THEN** 每条新工作记录的状态均为“进行中”

### Requirement: 工作记录状态展示与选择

系统 SHALL 在工作记录录入、编辑和卡片展示中提供单选状态能力。

#### Scenario: 录入时选择状态

- **WHEN** 用户录入工作记录
- **THEN** 系统显示当前配置的状态选项
- **AND** 用户只能选择一个状态

#### Scenario: 卡片显示状态

- **WHEN** 工作记录卡片渲染
- **THEN** 卡片显示该记录的状态标签
- **AND** 状态标签与项目、工作类型标签并列展示

#### Scenario: 编辑状态

- **WHEN** 用户编辑工作记录
- **THEN** 用户可以从当前状态配置中重新选择状态
- **AND** 保存后卡片立即显示新状态

### Requirement: 工作记录组合筛选

系统 SHALL 支持按项目、工作类型和状态筛选当前工作周记录。

#### Scenario: 单条件筛选

- **WHEN** 用户选择一个项目、工作类型或状态
- **THEN** 列表只显示匹配该条件的记录

#### Scenario: 多条件组合筛选

- **WHEN** 用户同时选择项目、工作类型和状态
- **THEN** 系统使用 AND 关系筛选记录
- **AND** 只显示同时满足所有已选条件的记录

#### Scenario: 全部选项

- **WHEN** 用户将某一筛选条件选择为“全部”
- **THEN** 该维度不限制筛选结果

#### Scenario: 筛选历史状态

- **WHEN** 当前记录包含已不在配置列表中的历史状态
- **THEN** 状态筛选仍显示该历史状态选项
- **AND** 用户可以筛选出对应记录

### Requirement: 周报状态标签

系统 SHALL 在现有周报模板的本周工作记录标签末尾追加工作状态。

#### Scenario: 生成本周工作记录

- **WHEN** 系统生成 Markdown 或纯文本周报
- **THEN** 本周记录使用 `[项目][工作类型][状态] 内容` 格式
- **AND** 状态为空的历史记录使用“已完成”

#### Scenario: 保持周报章节格式

- **WHEN** 系统生成周报
- **THEN** “本周完成工作”“下周工作计划”“本周得与失”等章节标题和顺序保持不变
- **AND** 系统不新增状态分组章节

#### Scenario: 保持下周计划格式

- **WHEN** 系统生成下周工作计划
- **THEN** 下周计划继续使用 `[项目][工作类型] 内容` 格式
- **AND** 不追加工作状态标签

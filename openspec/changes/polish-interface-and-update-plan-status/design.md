## Context

项目使用 Vue 3 和现有 SCSS 设计令牌，支持浅色/深色主题。视觉调整应复用现有结构，不引入新 UI 依赖。

## Goals / Non-Goals

- Goals: 保留原有极简视觉，只提升移动端易用性和基础可访问性。
- Non-Goals: 不重写页面、不改变导航结构、不引入字体或组件依赖。

## Decisions

- 使用原有白色、浅灰和柔和蓝色，不改动页面布局与卡片体系。
- 禁止渐变、光晕、玻璃效果和明显投影，不做装饰性视觉重构。
- 只添加移动端菜单、键盘焦点、reduced-motion 和移动端操作触控尺寸。
- 所有计划转换路径继续复用 `PLAN_RECORD_STATUS`，只修改一个共享常量。

## Risks / Trade-offs

- 视觉变化较小，但能避免破坏用户已经熟悉的界面。

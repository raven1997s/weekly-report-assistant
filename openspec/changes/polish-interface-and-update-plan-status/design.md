## Context

项目使用 Vue 3 和现有 SCSS 设计令牌，支持浅色/深色主题。视觉调整应复用现有结构，不引入新 UI 依赖。

## Goals / Non-Goals

- Goals: 提升视觉层级、状态可读性、交互反馈和移动端易用性。
- Non-Goals: 不重写页面、不改变导航结构、不引入字体或组件依赖。

## Decisions

- 使用冷灰背景与靛蓝单一主色，语义状态保留绿、橙、红等功能色。
- 通过全局令牌和共享组件样式覆盖大部分页面，仅对首页核心组件做局部增强。
- 深色模式由纯黑改为带蓝色调的深色表面，避免强烈割裂。
- 所有计划转换路径继续复用 `PLAN_RECORD_STATUS`，只修改一个共享常量。

## Risks / Trade-offs

- 现有页面存在较多 scoped 样式，部分页面只继承全局令牌，不做逐页重构。
- 状态颜色用于辅助扫描，同时保留文字标签，避免仅依赖颜色传达信息。

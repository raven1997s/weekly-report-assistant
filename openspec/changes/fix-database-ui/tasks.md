1. 启动开发服务器 `npm run dev`
2. 访问 http://localhost:5173/database
3. 默认显示"工作记录"表
4. 点击"下周计划"表按钮
5. **验证**：筛选按钮在数据加载期间应该禁用（不可点击）
6. 等待数据加载完成
7. 点击筛选按钮
8. **验证**：应该立即显示完整的字段筛选选项（如 project、content 等）
9. 重复测试"周报归档"和"定时任务"表

## ADDED Requirements

### Requirement: 草稿生成必须使用系统模板完整渲染邮件内容

系统 SHALL 在创建企业邮箱草稿时，基于当前保存的模板配置与签名配置渲染完整邮件 HTML 和纯文本内容。

#### Scenario: 使用当前设置生成草稿

- **WHEN** 用户发起创建企业邮箱草稿
- **THEN** 系统读取当前邮件模板配置与邮件签名配置
- **AND** 系统生成包含模板文案与签名的完整邮件内容
- **AND** 系统将该内容写入企业邮箱草稿箱

### Requirement: 系统必须支持邮件模板预览

系统 SHALL 提供邮件模板预览接口，允许前端在未保存时使用临时覆盖配置实时查看最终渲染结果。

#### Scenario: 使用临时配置预览邮件

- **WHEN** 前端调用邮件预览接口并传入临时模板或签名配置
- **THEN** 系统基于临时覆盖配置返回邮件主题、HTML 与纯文本内容
- **AND** 不修改数据库中已保存的正式配置

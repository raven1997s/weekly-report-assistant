# email-draft-export Specification

## ADDED Requirements

### Requirement: 系统必须支持阿里企业邮箱草稿箱导出

系统 SHALL 支持将当前周报保存到阿里企业邮箱草稿箱，供用户在邮箱网页端继续检查和发送。

#### Scenario: 用户保存周报到草稿箱

- **GIVEN** 用户已完成企业邮箱配置
- **AND** 当前存在可导出的周报内容
- **WHEN** 用户在周报预览点击“保存到阿里邮箱草稿箱”
- **THEN** 系统调用后端创建草稿接口
- **AND** 后端将邮件写入企业邮箱草稿箱
- **AND** 前端显示“已保存到草稿箱”成功提示
- **AND** 如果配置了邮箱网页地址，系统支持打开邮箱草稿箱页面

### Requirement: 系统必须支持内置邮件模板选择

系统 SHALL 提供系统内置的邮件模板选择能力，并允许使用固定 HTML 模板渲染草稿内容。

#### Scenario: 用户选择内置模板创建草稿

- **GIVEN** 系统已内置周报邮件模板
- **WHEN** 用户在周报预览选择模板并创建草稿
- **THEN** 系统使用选中的模板渲染邮件 HTML
- **AND** 模板内容包含标题、固定表格结构和周报正文占位区
- **AND** 默认不包含邮箱签名

### Requirement: 系统必须支持企业邮箱配置管理

系统 SHALL 提供阿里企业邮箱连接配置的保存和读取能力。

#### Scenario: 用户保存企业邮箱配置

- **WHEN** 用户在设置页输入邮箱地址、IMAP 服务器、端口、安全密码
- **AND** 输入默认收件人、抄送或密送信息
- **AND** 点击保存
- **THEN** 系统将配置保存到后端设置存储
- **AND** 页面刷新后仍能读取到已保存配置

#### Scenario: 用户未配置完整参数

- **WHEN** 用户尝试保存到草稿箱
- **AND** 邮箱地址、IMAP 服务器、端口或安全密码缺失
- **THEN** 系统阻止提交
- **AND** 提示用户先完成企业邮箱配置

### Requirement: 系统必须通过后端写入草稿箱

系统 SHALL 由后端负责连接 IMAP 并写入草稿箱，前端不得直接连接邮件服务器。

#### Scenario: 后端创建草稿

- **WHEN** 前端调用创建草稿接口
- **THEN** 后端使用已保存的邮箱配置建立 IMAP 连接
- **AND** 将邮件内容以草稿形式写入草稿箱目录
- **AND** 自动带入已配置的默认收件人、抄送、密送
- **AND** 响应返回成功结果和实际写入的邮箱目录名

### Requirement: 系统必须提供明确的失败反馈

系统 SHALL 在草稿创建失败时向用户提供明确可理解的错误提示。

#### Scenario: 安全密码错误

- **WHEN** 后端连接 IMAP 认证失败
- **THEN** 系统返回失败响应
- **AND** 前端提示“邮箱登录失败，请检查邮箱账号或安全密码”

#### Scenario: 草稿箱目录不存在

- **WHEN** 后端无法写入指定草稿箱目录
- **THEN** 系统返回失败响应
- **AND** 前端提示用户检查草稿箱文件夹配置

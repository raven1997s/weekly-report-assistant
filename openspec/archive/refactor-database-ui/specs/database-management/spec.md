## MODIFIED Requirements

### Requirement: 表切换功能

系统 SHALL 提供现代化的表切换界面，使用 Segmented Control 风格替代独立按钮。

#### Scenario: 切换表

- **WHEN** 用户点击表切换器中的某个分段
- **THEN** 系统加载该表的数据，重置分页和搜索状态
- **AND** 激活分段显示卡片效果和微阴影

#### Scenario: 显示表信息

- **WHEN** 表切换器渲染
- **THEN** 显示表的中文名称和行数徽章
- **AND** 使用统一背景容器包裹所有分段
- **AND** 激活分段与非激活分段有明显视觉区分

#### Scenario: 切换动画

- **WHEN** 用户切换表
- **THEN** 数据区域显示淡入动画效果
- **AND** 动画持续时间约 200ms

### Requirement: 搜索功能

系统 SHALL 提供优化的搜索界面，搜索栏和筛选按钮置于统一卡片容器中。

#### Scenario: 搜索输入

- **WHEN** 用户在搜索框输入关键词
- **THEN** 系统在 500ms 防抖后执行搜索

#### Scenario: 搜索栏布局

- **WHEN** 搜索筛选栏渲染
- **THEN** 搜索栏和筛选按钮在同一卡片容器内
- **AND** 使用圆角边框和柔和阴影
- **AND** 筛选按钮始终可见，不会被布局遮挡

### Requirement: 数据展示

系统 SHALL 以现代化表格形式展示数据，使用无边框设计和行交替底色。

#### Scenario: 表格样式

- **WHEN** 数据表格渲染
- **THEN** 表格使用圆角卡片容器
- **AND** 移除表格外边框
- **AND** 使用行交替底色提升可读性
- **AND** 表头粘性定位时显示底部阴影

#### Scenario: 单元格悬浮

- **WHEN** 用户悬浮在表格行上
- **THEN** 该行显示高亮背景色
- **AND** 过渡动画平滑

#### Scenario: JSON 字段显示

- **WHEN** 字段值为 JSON 字符串
- **THEN** 系统显示清晰的 JSON 预览图标
- **AND** 用户点击后打开弹窗查看完整内容

#### Scenario: 布尔字段显示

- **WHEN** 字段值为 0 或 1
- **THEN** 系统显示彩色徽章样式的「是」/「否」

### Requirement: 高级筛选面板

系统 SHALL 提供优化的筛选面板，使用 slide-down 动画展开。

#### Scenario: 打开筛选面板

- **WHEN** 用户点击筛选按钮
- **THEN** 系统以 slide-down 动画展开筛选面板
- **AND** 按钮状态变为激活状态

#### Scenario: 筛选面板布局

- **WHEN** 筛选面板渲染
- **THEN** 使用紧凑的网格布局
- **AND** 筛选项标签清晰可读
- **AND** 应用和重置按钮位置明确

### Requirement: 分页功能

系统 SHALL 提供美化的分页器，使用圆角按钮和清晰的页码信息。

#### Scenario: 分页器样式

- **WHEN** 分页器渲染
- **THEN** 使用圆角按钮样式
- **AND** 显示当前页码、总页数和总记录数
- **AND** 禁用状态有明显视觉区分

#### Scenario: 翻页功能

- **WHEN** 用户点击上一页或下一页按钮
- **THEN** 系统加载对应页的数据

### Requirement: 响应式设计

系统 SHALL 支持桌面端、平板端和移动端访问，布局自适应。

#### Scenario: 移动端布局

- **WHEN** 屏幕宽度 < 768px
- **THEN** 表切换器可横向滚动
- **AND** 搜索筛选栏垂直排列
- **AND** 表格支持横向滚动
- **AND** 分页器使用紧凑布局

#### Scenario: 桌面端布局

- **WHEN** 屏幕宽度 >= 1024px
- **THEN** 表切换器水平排列
- **AND** 搜索筛选栏水平排列
- **AND** 表格充分利用可用宽度

### Requirement: 加载和空状态

系统 SHALL 提供美观的加载状态和空状态提示。

#### Scenario: 加载状态

- **WHEN** 数据正在加载
- **THEN** 系统显示加载动画
- **AND** 加载动画使用主题色

#### Scenario: 空状态

- **WHEN** 表中没有数据或搜索无结果
- **THEN** 系统显示美观的空状态图标
- **AND** 显示友好的提示文案

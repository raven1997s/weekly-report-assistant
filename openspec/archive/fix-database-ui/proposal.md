# fix-database-ui

## 问题描述

数据库管理页面存在 UI 体验问题：点击"下周计划"、"周报归档"、"定时任务"等表按钮后，**筛选按钮完全消失**（不是筛选字段的问题）。

其他表（"工作记录"、"应用设置"）上筛选按钮显示正常。

## 根因分析

经过代码分析，筛选按钮（`.filter-toggle-btn`）在模板中没有 `v-if` 条件，应该始终显示。

**待确认的可能原因**：
1. CSS 布局问题 - `.search-bar` 缺少 `position: relative`，绝对定位的搜索图标可能导致布局异常
2. JavaScript 错误 - 切换到特定表时可能触发错误导致 Vue 渲染中断
3. 数据问题 - 某些表的数据结构可能导致组件异常

> [!IMPORTANT]
> 需要用户协助：请在浏览器开发者工具中检查切换到 "下周计划" 表后的控制台错误信息

## 提议的修复方案

### 方案 1: 修复 CSS 布局
在 `.search-bar` 中添加 `position: relative`，确保搜索图标的绝对定位正确：

```scss
.search-bar {
  position: relative;  // 添加此行
  display: flex;
  gap: $spacing-3;
  flex: 1;
}
```

### 方案 2: 增强错误边界
如果是 JavaScript 错误导致渲染问题，需要在 Vue 组件中添加错误处理。
